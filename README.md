# 茨城県 不動産マップ（水戸市 / ひたちなか市）

茨城県の **大字（街）の区切り線・用途地域・小中学校区・各種施設** を
地理院地図の上にまとめた、不動産業務向けの参照マップ（静的ウェブサイト）。
**水戸市**と**ひたちなか市**に対応（同一フォルダの多都市構成）。

## 使い方
- `起動.bat` をダブルクリック（または `index.html` をブラウザで開く）と、**都市選択画面**が開きます。
- そこから「水戸市」または「ひたちなか市」を選びます（各マップ左上のナビでも相互に行き来できます）。
- 地図タイルの読み込みにインターネット接続が必要です。

## ページ構成
- `index.html` … 都市選択ハブ
- `mito.html` … 水戸市マップ ／ `hitachinaka.html` … ひたちなか市マップ
- データは `data/`（水戸=`mito-*.js`、ひたちなか=接頭辞なし）。各HTML冒頭の `window.CITY_CONFIG` で初期表示位置を指定。

### 主な機能
- **大字の区切り線**＋地名ラベル（ズーム13以上で表示）
- **地区をクリック** → 人口・世帯数・所属する小中学校区・**隣接する地区一覧**を表示。さらに **丁目の境界が薄線で表示**されます
  - 隣接地区のチップをクリックすると、その地区へ移動（地名を覚える学習に）
- **用途地域**（12種を色分け・建ぺい率/容積率をクリックで表示）。**濃さ（不透明度）スライダー**と**種別ごとのON/OFF**つき
- **地区検索**（例：東石川）でその地区へズーム
- レイヤー切替
  - 区域（面）：大字 / 地名ラベル / 用途地域 / 小学校区 / 中学校区
  - 学校・施設（点）：小学校 / 中学校 / 駅 / スーパー / 商業施設（コストコ等）/ ホームセンター / コンビニ / 飲食店 / 病院 / 銀行・郵便局 / 公共施設 / 工場（日立系）/ 嫌悪施設（刑務所等）/ ランドマーク
- 背景地図：淡色 / 標準 / 写真（航空写真）

## 施設の追加・修正
`data/poi.js` の配列を編集するだけです。

```js
{ "name": "〇〇スーパー", "cat": "supermarket", "lat": 36.39, "lng": 140.54 }
```
- `cat`: station（駅）/ supermarket（スーパー）/ shopping（商業施設）/ homecenter（ホームセンター）/
  conveni（コンビニ）/ restaurant（飲食店）/ hospital（病院）/ finance（銀行・郵便局）/
  public（公共施設）/ factory（工場）/ nuisance（嫌悪施設）/ school_e（小学校）/ school_j（中学校）/ landmark（ランドマーク）
- 緯度経度は Google マップで右クリック →「この場所について」で取得できます。

## データ出典
- 背景地図：国土地理院タイル
- 大字・丁目境界：総務省 令和2年国勢調査 町丁・字等別境界データ（NII Geoshape 経由）
- 用途地域：国土交通省 国土数値情報 A29（2019年）
- 小学校区／中学校区：
  - ひたちなか市：国土交通省 国土数値情報 A27・A32（2023年）
  - 水戸市：A27/A32 に水戸市が未収録のため、**水戸市公式「学区検索」の通学区域**をもとに作成
- 施設・学校点：© OpenStreetMap contributors
