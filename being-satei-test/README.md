# ビーイング ひたちなか市かんたん査定（社内確認用テスト版）

社内で画面と計算方法を確認するための静的サイトです。価格は検証中の概算であり、成約価格を保証しません。

## 機能

- 土地／土地＋建物（住宅）を査定。事業用は個別相談の案内。
- 地番不要。町名の候補選択と直接入力を同じ欄で使用。
- 市街化区域・市街化調整区域・不明を選択。㎡入力時に坪も表示。
- 同じ町・隣接町・近隣から土地事例を最大５件選定。１〜４件でも計算し、０件では近傍の公示地価から参考価格を算出。両方なければ価格を表示しない。
- 住宅の価格は土地評価＋再調達原価を築年数で減価した建物評価。構造別の標準単価・耐用年数を使用。
- 基準価格の−5％〜＋15％を表示。結果のすぐ下からLINE・電話相談へ。
- 結果表示前に約５秒の準備表示。入力変更で待機中の結果を取り消す。

## データ

国土交通省「不動産情報ライブラリ」のXIT001、XPT002から取得した公開データを加工しています。取得日を画面に表示。利用者ごとのAPIアクセスは行いません。

出典：https://www.reinfolib.mlit.go.jp/

キーはこのリポジトリに含みません。`data/market.json` は取得済みの公開事例・公示地価です。元データの匿名化・丸め、欠測、地域差等により精度に限界があります。地番を入力しても町域までの比較で、個別の道路・形状・建築可否・修繕状況は確認していません。

住所入力はブラウザ内で処理し、保存・送信しません。問い合わせボタンは会社のLINE・電話へのリンクで、自動送信しません。

## 運用

HTML/CSS/JavaScriptのみ。GitHub Pagesはこのテスト版の確認用です。本番の営業サイトとして運用する際は、用途と利用条件に適合するホスティングへ移す計画です。`noindex`を設定していますが、アクセス制限ではありません。

データ更新は管理者が別のローカル取得処理で実行し、公開用のJSONだけを更新します。査定工房の本体、APIキー、社内設定ファイルはアップロードしません。
